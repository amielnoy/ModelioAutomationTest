Framework Architecture

Playwright · TypeScript · FastAPI · Prometheus · Grafana · Allure 3 · GitHub Actions

Overview

A production-grade end-to-end automation framework testing the SauceDemo web UI, the JSONPlaceholder REST API, and a custom FastAPI health service that monitors both targets. All 18 tests run in parallel across three Playwright projects and are reported in Allure 3, deployed to GitHub Pages after every push to main.

TS UI Tests
7 Chromium tests covering login, cart, checkout, and product sorting on SauceDemo.
TS API Tests
6 tests exercising GET, POST, PUT, DELETE on JSONPlaceholder /posts.
TS Health Tests
5 tests verifying the FastAPI health endpoints and the OpenAPI/Swagger spec.
PY FastAPI Service
Health & readiness API that probes SauceDemo and JSONPlaceholder; exposes Swagger UI and /metrics.
MON Prometheus + Grafana
Scrapes /metrics every 15 s; Grafana dashboard shows request rate, p95 latency, error rate, uptime.
CI GitHub Actions
Runs tests, generates Allure report, and deploys to GitHub Pages on every push to main.

Layer Breakdown

1 — Test Layer (tests/)

Thin specs: each test imports from src/fixtures, calls high-level methods, and wraps steps in allureStep(). No page/API implementation detail leaks in.

2 — Fixture Layer (src/fixtures/index.ts)

Single test.extend() that wires all pages, API services, workflows, and auto-fixtures together. Provides:

  • authenticatedInventory — logs in and returns an InventoryPage
  • postsApi / healthApi — API service instances scoped per test
  • mockApi — page.route() stub helper with automatic teardown
  • _failureCapture (auto) — attaches screenshot, video, trace to Allure on failure
  • _serverLinks (auto) — adds Allure links to every test result

3 — Page Object Layer (src/pages/)

Each page extends BasePage which holds the Page reference and common helpers. Pages expose intent-revealing methods (login(), addToCart(), proceedToCheckout()) and encapsulate all data-test attribute selectors.

4 — API Service Layer (src/api/)

ApiClient wraps Playwright's APIRequestContext. PostsApi and HealthApi extend it with typed endpoint methods. No raw request.get() calls appear in tests.

5 — Workflow Layer (src/workflows/)

Multi-step sequences (AuthWorkflow.login(), CartWorkflow.addItems(), CheckoutWorkflow.complete()) that compose Page Object calls, keeping test bodies short.

6 — Utility Layer (src/utils/)

allure.ts
Wraps allure-js-commons. allureStep() chains Playwright's test.step(), Allure's step, and the logger in one call.
config.ts
Single source of truth for env vars. requireEnv(key, fallback) treats empty strings as missing — critical for GitHub secrets.
logger.ts
Dual-sink: console.log + append to logs/YYYY-MM-DD.log. Levels: INFO, STEP, PASS, FAIL, WARN, DEBUG.
global-setup.ts
Prints the server-links banner at run start. Local-only links (Swagger, FastAPI, Grafana) omitted in CI.

Reporting Stack

Allure 3 (GitHub Pages)
Published at every push. Includes history trend, categories (flaky/product defect/test defect), environment info with test counts, per-test steps, request/response attachments, screenshot + video + trace on failure.
Playwright HTML
Fast local report. Uploaded as playwright-report artifact. Kept 14 days.
JUnit XML + JSON
test-results/junit.xml for CI dashboards; results.json used by SummaryReporter and the GitHub step summary script.
CLI Summary Table
SummaryReporter.onEnd() prints Total / Passed / Failed / Skipped / Flaky / Duration after every run. Same table appears in GitHub's step summary as markdown.
Daily Log File
logger.ts appends every step to logs/YYYY-MM-DD.log with timestamps and severity levels.
Grafana Dashboard
4 panels: HTTP request rate, p95 response latency, error rate, service uptime. Powered by Prometheus scraping the FastAPI /metrics endpoint.

Key Design Decisions

DecisionRationale
if (!value) in requireEnvGitHub secrets resolve to "" (empty string) when unset — ?? fallback doesn't catch that.
expect.timeout in playwright.configWithout it, Playwright defaults assertion timeout to 5 s, causing all UI tests to time out in CI.
Java (JDK 17) in Dockerfile & CIallure-commandline is a Java binary — required inside Docker and in the GitHub Actions runner.
.nojekyll in allure-reportJekyll (default GitHub Pages processor) silently drops files/dirs whose names start with _, causing Allure 3 test-case fetches to 404.
Custom SummaryReporterglobalTeardown stdout is swallowed by Playwright's subprocess model; a custom reporter's onEnd runs in the main process.
Localhost links skipped in CIGrafana/FastAPI/Swagger run only via Docker locally; embedding localhost URLs in the GitHub Pages Allure report would always 404.
fullyParallel: true + 4 workersAll 18 tests complete in ~5 s locally and in CI; no shared browser state between tests.
Allure history via artifact downloaddawidd6/action-download-artifact fetches the previous run's history/ folder so the trend graph builds up across runs.
